A register is a group of flip-flops used to store binary information temporarily.
An n-bit register consists of n flip-flops and can store n bits of data.

Registers that are capable of moving information position wise upon the
occurrence of a clock signal are called shift registers. A shift register is a
sequential circuit that stores binary data and shifts it from one flip-flop to
another for every clock pulse.

These registers are normally classified by whether they can move the
information in one or two directions, i.e Unidirectional or Bidirectional.

The manner in which information is entered into and outputted from a register
is another way in which they are categorized [SISO,SIPO,PIPO,PIPO]Major applications of Registers…
1.   Temporary Data Storage: Stores intermediate data during arithmetic and logical operations in a CPU.
2.   Data Transfer: Transfers binary data between different sections of a processor.
3.   Instruction Storage: Instruction Register (IR) stores the currently executing instruction.
4.   Address Storage: Memory Address Register (MAR) holds the address of the memory location to be accessed.
5.   Accumulator: Stores intermediate results of arithmetic and logical operations.
6.   Buffering: Temporarily holds data during transfer between devices operating at different speeds.
7.   Processor Operations: General-purpose registers store operands, addresses and intermediate results.

Major applications of Shift Registers…
1. Serial-to-Parallel Conversion: Converts serial data received from communication channels into parallel data using SIPO
registers.
2. Parallel-to-Serial Conversion: Converts parallel data into serial form for transmission using PISO registers.
3. Temporary Data Storage: Stores binary information temporarily during digital operations.
4. Time Delay Circuits: Provides a digital delay by shifting data through successive flip-flops.
5. Sequence Generation: Generates predefined binary sequences using ring counters and Johnson counters.
6. Arithmetic Operations: Performs serial addition, multiplication and division by shifting binary data.
7. Data Transfer: Transfers data between digital systems and communication interfaces.
8. Digital Signal Processing: Used in digital filters, delay lines and signal-processing circuits.
9. LED Display Control: Controls running LED patterns and sequential lighting applications.
10. Pseudo-Random Sequence Generation: Linear Feedback Shift Registers (LFSRs) generate pseudo-random binary

flop, forming a closed loop. As a result, the data stored in the register continuously circulates from one flip-flop to the next
with every clock pulse.

In a 4-bit circular shift register:
• Four D flip-flops are connected in cascade.
• The output of the last flip-flop is fed back to the input of the first flip-flop.
• All flip-flops receive a common clock signal.Universal Shift Register
A Universal Shift Register (USR) is a sequential logic circuit that can perform
         bidirectional shifting and supports SISO,SIPO,PISO,PIPO.
1. A 4-bit universal shift register consists of:
•   Four D flip-flops: FF3, FF2, FF1 and FF0 (whose o/ps are Q3,Q2,Q1 and Q0)
•   Four 4:1 multiplexers.
•   Two mode-control inputs: S1 and S0.
•   Four parallel data inputs: P3, P2, P1 and P0.
•   Serial inputs for shifting in both directions.
•   A common clock signal.

2. Multiplexer connections
Each D flip-flop is preceded by a 4:1 MUX. The MUX selects one of four possible inputs based on the mode-control
signals S1 and S0.

    S1                          S0                          Selected input            Operation
    0                           0                           Present output Q          Hold
    0                           1                           Adjacent higher bit       Shift right
    1                           0                           Adjacent lower bit        Shift left
    1                           1                           Parallel input P          Parallel load3.Operation of the Universal Shift Register
Assume the register contains four bits: Q3,Q2,Q1,Q0

A. Hold operation (S1S0 = 00)
The output of each flip-flop is fed back to its own input through the MUX.
On the active clock edge, the existing data remains unchanged.

B. Shift-right operation (S1S0 = 01)
Each bit shifts one position towards the right (LSB).
The serial input SR enters the MSB position.
The LSB is shifted out.

C. Shift-left operation (S1S0 = 10)
Each bit shifts one position towards the left (MSB).
The serial input SL enters the LSB position.
The MSB is shifted out.

D. Parallel-load operation (S1S0 = 11)
All four bits are loaded simultaneously.
Each flip-flop receives its corresponding parallel input.Operation                  Control   Register content
