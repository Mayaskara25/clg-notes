Simple Queue: Enqueue Operation

 Add(item)                                             Step 1
 {
     if (IsFull())                                     Check whether the queue is full.
         QueueFull();
     else {
         rear++;
         queue[rear] = item;
     }                                                 Step 2
 }                                                     Advance rear and store item at queue[rear].

                    Insertion always occurs at the rear in a simple queue.

Simple Queue: Dequeue Operation

 Delete(item)                                         Step 1
 {
     if (IsEmpty())                                   Check whether the queue is empty.
         QueueEmpty();
     else {
         item = queue[front];
         front++;
     }                                                Step 2
 }                                                    Return the front item and advance front.

                   Deletion always occurs at the front in a simple queue.

Why a Linear Array Queue Has a Limitation
After deletions, free positions can appear at the beginning while rear moves toward the last
                                       array position.

             0              1         2            3            4         5

                                      C            D            E         F

         unused positions                                           rear near end

  The intuitive array implementation may require elements to move to reclaim unused space.
  In the worst case, such shifting can take O(n) time.
  Circular queues remove the need for this repeated shifting.

 {                             Case 1: Empty queue
     new = allocate Node;      The first node becomes both front and rear.

Array Queue vs Linked Queue

    Aspect                    Array implementation                      Linked-list implementation

     Storage         Fixed capacity (unless dynamic array is used)   Dynamic; grows as nodes are allocated

  Memory layout                       Contiguous                     Non-contiguous nodes linked by pointers

    Overflow                  When capacity is reached                  Only when memory allocation fails

   Space reuse             Circular queue reuses positions           Freed nodes can be returned to memory

Pointers / indices               front and rear indices                    front and rear node pointers

Enqueue / Dequeue          O(1) with suitable representation             O(1) with front and rear pointers

Choosing the Appropriate Queue

 Simple Queue
 Need strict FIFO service and straightforward operations.

 Circular Queue
 Need fixed-size array storage with efficient reuse of released positions.

 Deque
 Need insertion/deletion at both ends.

 Priority Queue
 Need service according to priority rather than pure arrival order.
