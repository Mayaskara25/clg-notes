N-ary Tree — Definition
The value of N determines the maximum number of children a node can have.

      An N-ary tree is a tree in which each node has AT MOST N

A special type of tree with a strict limit on children.

What Is a Binary Search Tree?
BST property is applied recursively to every node.

    A Binary Search Tree (BST) is a binary tree in which, for every node,
      values in the LEFT subtree are smaller and values in the RIGHT
                            subtree are larger.

                       SMALLER                                          LARGER
                                                     50

                                  30                                 70

         For duplicates, a course must define a consistent policy; here we assume distinct keys.Go, change the world

Remember two simple rules and apply them consistently.

   STEP 1      First child becomes            Connect each node to its first child using the

               LEFT child
