Queue: Basic Concept

 A queue is an ordered list in which insertions take place at one end and
                deletions take place at the opposite end.

FIFO: First-In-First-Out

     The element that enters first is the element that leaves first.
        First inserted                                        First deleted

            10           20        30           40

       Enqueue: add the new item at the rear.
       Dequeue: remove the item at the front.
       Thus, the ordering of service follows arrival order.

Queue as an Abstract Data Type (ADT)

 The ADT specifies what a queue does, independent of how the queue is represented or
                                   implemented.

      CREATEQ               Create an empty queue with a specified maximum size.

      ISEMPTYQ              Determine whether the queue contains no elements.

      ISFULLQ               Determine whether the queue has reached its capacity.

   ADDQ / ENQUEUE           Insert an item at the rear of the queue.

      DELETEQ /
                            Remove and return the item at the front.
      DEQUEUE

                  Textbook terminology: Horowitz et al. use AddQ/DeleteQ; these correspond to enqueue/dequeue.

Queue Operations: Enqueue and Dequeue

 ENQUEUE (ADDQ)                                DEQUEUE (DELETEQ)
 Adds a new element at the REAR.               Removes the element at the FRONT.

 1. Check whether the queue is full.           1. Check whether the queue is empty.
 2. Advance rear.                              2. Advance front.
 3. Store the new item at queue[rear].         3. Return the removed item.

 Effect: the queue grows at the rear.          Effect: the queue shrinks at the front.

       Error conditions: Queue Full during insertion; Queue Empty during deletion.

Array Representation of a Simple Queue

A one-dimensional array can store the queue, with front and rear maintaining its boundaries.
           index

            0             1         2           3            4              5   6

            A            B          C           D

          elements

                     front → A                                      D ← rear

         Sequential storage is simple and efficient for basic operations.
         However, a linear array queue can waste space after deletions.

Enqueue: Step-by-Step Trace

              Suppose the queue contains A, B, C and we enqueue D.

         Before                           Advance rear                       Insert D

    A     B       C                   A      B     C                     A     B     C       D

  The new item is always placed at the rear; existing elements keep their relative order.

Dequeue: Step-by-Step Trace

       Starting with A, B, C, D, dequeue removes A and advances the front.

         Before                        Remove A                        New front

   A     B        C   D                  B    C     D                    B     C       D

   The removed item is the front element. The next element becomes the new front.

          unused                                  active elements                   rear at end

   The cells at the beginning are free, but a simple linear implementation may still report the queue as
   full when rear reaches the last position.
   Shifting elements to reclaim space can make an insertion or deletion O(n).

Circular Queue

  A circular queue treats the array as if the last position is connected back to the
                                         first.
                                               1
                                  0                         2

                                  5                         3
                                               4

  When rear reaches the last index, the next position can wrap to index 0 if that position is
                                           free.

                   Typical wrap-around rule: next position = (position + 1) mod
                                      MAX_QUEUE_SIZE

                                                                                                    13Go, change the world

Circular Queue: Enqueue and Dequeue

        Circular indexing reuses positions released by earlier dequeue operations.

 ENQUEUE IN CIRCULAR QUEUE                        DEQUEUE IN CIRCULAR QUEUE
 1. Check whether the queue is full.              1. Check whether the queue is empty.
 2. Move rear to the next circular position.      2. Remove the item at front.
 3. Insert the new item there.                    3. Move front to the next circular position.
 4. Continue from index 0 after the last index.   4. Freed cells can later be reused.

     Main benefit: avoids unnecessary shifting and makes better use of a fixed-size
                                        array.

Priority Queue

In a priority queue, removal is determined by priority rather than strictly by arrival
                                       time.

        Job A                         Job B                  Job C                           Job D
        Priority 3                   Priority 1             Priority 2                       Priority 1

    If lower numerical value means higher priority, Job B and Job D are served before Job C and
                                               Job A.

Queue Operation Complexity

With front and rear maintained appropriately, basic queue operations can be performed efficiently.

         Operation         Typical array queue                          Purpose

          Enqueue                  O(1)                                Insert at rear

          Dequeue                  O(1)                             Remove from front

         Front / Peek              O(1)                             Inspect next item

            Rear                   O(1)                     Inspect most recently inserted item
           Caution: shifting elements in a linear array queue may require O(n) movement.
